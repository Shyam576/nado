# Jarvis — minimal server/headless install (bot mode + dashboard, no LLM).
#
# Use this instead of requirements.txt when deploying to a server that only
# runs `python main.py bot` — no microphone, no display, no local LLM. It
# deliberately excludes:
#   - llama-cpp-python (local LLM) — everything still works without it: all
#     slash commands, the whole dashboard, nudges, backups. Only free-form
#     chat and a handful of LLM-drafted commands (/draft-email, /rewrite,
#     /notes, /decide, /logs summary, the mentor summary text) degrade to a
#     plain "try again"/"not available" reply instead of erroring — see
#     brain.py's ask() and modules/execution.py's generate_mentor_summary().
#     Add it back (`llama-cpp-python>=0.3.0`) if you later run a model here.
#   - rich, openai-whisper, scipy, pyaudio — voice_mode's LIVE MIC capture
#     only (main.py's voice_mode/text_mode paths, and voice.py's listen(),
#     now import these lazily — bot mode never touches them, so they don't
#     need to be installed at all on a bot-only server).
#   - pyautogui, Pillow, pyscreeze — desktop computer-control actions
#     (open app, screenshot, click). No display on a headless server for
#     these to act on; also lazily imported, so this is just saving the
#     install, not required for correctness.
#
# Still included below: edge-tts, pyttsx3, numpy, SpeechRecognition — these
# ARE needed even in bot mode, because bot/telegram_bot.py and
# bot/discord_bot.py call voice.synthesize_to_file() to send a voice-note
# reply when you send Jarvis a voice message (incoming transcription itself
# uses modules/transcription.py's own lazy Whisper loader, not voice.py's).
# None of these four need a native library — no apt-get beyond tesseract.
#
# Install with: python3 -m pip install -r requirements-server.txt
